# Diretrizes de Execução Autônoma - Impulso Stone Reels MCP

1. **Fluxo Sequencial Estrito**: Implemente uma Spec por vez (Spec 01 -> Spec 07). É proibido iniciar a próxima Spec antes que todos os comandos da seção "Métricas de Autoverificação" da Spec atual passem com sucesso (`exit code 0`).
2. **Isolamento de Dependências Humanas**: Se uma API externa não estiver configurada no `.env`, o código DEVE acionar automaticamente o *Tier 3 (Fallback Local)* sem quebrar a execução. Nunca pare a implementação pedindo chaves de API; registre quaisquer pendências em `docs/HUMAN_DEPENDENCIES.md`.
3. **Documentação de Decisões Técnicas (ADRs)**: Ao concluir cada Spec, crie ou atualize o respectivo arquivo em `docs/adr/` documentando os *trade-offs*, parâmetros calibrados e justificativas técnicas.
4. **Higiene de Mídia**: Todo vídeo final deve ser validado via `ffprobe` garantindo `1080x1920`, `yuv420p`, `H.264`, `CFR` (Constant Frame Rate) e áudio `AAC`.

ADR-001: Topologia Híbrida MCP com Uso Integral das 3 Primitivas (Prompts, Resources, Tools)

Contexto: Servidores MCP que expõem apenas Tools forçam o LLM a gastar chamadas de inferência e tokens de contexto para buscar transcrições e listas de cenas.   
Arquitetura MCP Gratuita para Reels.md

Decisão: Expor perfis CNAE e resumos multimodais (transcript.json, scenes.csv) como Resources anexados pelo cliente (custo zero de tool call), templates dos 5 frameworks como Prompts e processamento pesado de mídia como Tools.   
Arquitetura MCP Gratuita para Reels.md

ADR-002: Roteamento em Cascata (Zero-Cost Cascade) e Isolamento de Dados Sensíveis

Contexto: Limites voláteis de free tiers (RPD/TPM da Groq, Neurônios diários da Cloudflare, quota de 300s/dia da ZeroGPU) e cláusula de treino de dados no plano gratuito da Gemini API.   
Arquitetura MCP Gratuita para Reels.md

Decisão: Implementar ZeroCostCascadeRouter com leitura de headers HTTP em tempo real, cache SHA-256 local de 24h e desvio automático para inferência local (Ollama Qwen2.5-VL, WhisperX, Piper TTS) quando houver limite de quota ou presença de dados sensíveis do MEI.   
Arquitetura MCP Gratuita para Reels.md

ADR-003: Animação Determinística 2.5D Local vs. Vídeo Generativo (I2V) para Produtos

Contexto: APIs comerciais de geração de vídeo são pagas por segundo e modelos difusores re-sintetizam pixels, deformando logotipos, rótulos e texturas de produtos reais (bolos, roupas, peças).   
Arquitetura MCP Gratuita para Reels.md

Decisão: Adotar pipeline local 2.5D (Depth Anything V2 + OpenCV DIS Optical Flow) com ancoragem no plano de pivô (PIVOT_CENTER_BOX), garantindo deslocamento líquido zero e deformação zero nos pixels do produto a custo operacional nulo.   
Arquitetura MCP Gratuita para Reels.md

ADR-004: Calibração Neuromarketing de Jump-Cuts (Fluência vs. Modelo AST) e Higiene A/V

Contexto: Necessidade de reter atenção nos primeiros 3 segundos (Swipe Zone) e evitar decaimento na Pacing Slope (> 5s) sem amputar fonemas.   
Arquitetura MCP Gratuita para Reels.md

Decisão: Calibrar cortes conforme Dost & Huang (2026) em estilo Seamless (PAD=0.090s, 0.517 ou 0.331 cortes/s para Likes) e Overlapping (PAD=0.015s, 0.331 cortes/s para retenção em vídeos técnicos), mantendo o corte de áudio no milissegundo exato com afade de 15ms e normalização prévia para CFR (-vsync cfr).   
Arquitetura MCP Gratuita para Reels.md

ADR-005: Bloqueio de Licenças Não-Comerciais em Ativos de Áudio e Voz

Contexto: Planos gratuitos da ElevenLabs, Epidemic Sound e Freesound proíbem uso comercial em seus Termos de Serviço.   
Arquitetura MCP Gratuita para Reels.md

Decisão: Bloquear essas rotas no schema de renderização e restringir o sistema a motores comercialmente livres (edge-tts, Kokoro-82M, Piper TTS CC0, Pixabay API com cache de 24h e anexação nativa via bibliotecas oficiais do Instagram/TikTok).   
Arquitetura MCP Gratuita para Reels.md
