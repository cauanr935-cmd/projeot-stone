# ADR-900 — Emendas aos testes de aceitação

Os testes em `tests/acceptance/` e `tests/verify_final_reel.py` são contrato
(CLAUDE.md §1.5). Só podem mudar quando estiverem **comprovadamente
errados**. Cada emenda precisa de uma entrada abaixo; o `spec-verifier`
reprova emendas que apenas afrouxam critérios.
